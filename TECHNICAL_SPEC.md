# DEVELOPER MASTER PROMPT & TECHNICAL SPECIFICATION
**Project:** iTMounts AI Lab (SignalBoost Engine)  
**Target Platform:** Production Multi-Tenant Governed Distillation & Certification Lab  
**Core Motto:** "Graduation is not the product. Trustworthy selection is the product."

---

### EXECUTIVE SUMMARY & SYSTEM GOAL
We are building **iTMounts AI Lab**, a governed environment where enterprise customers use a **Credit Ledger** to experiment with models, data, teachers, compute, and APIs to create specialized AI workers.

Unlike conventional fine-tuning platforms that charge per GPU-hour regardless of output quality, iTMounts is a **Quality-Gated Certification Engine**. The platform orchestrates training/distillation, independently evaluates candidate models, rejects those that fail, graduates those that meet standards, and tracks graduate performance in production.

---

### CORE ARCHITECTURAL DIRECTIVES

#### 1. The Core Value Proposition: Selection Over Execution
* The system MUST NOT promise positive capability gains on every run. Research involves failure.
* The system GUARANTEES **Veracity**: A regressed or unsafe artifact will NEVER be falsely certified or graduated.
* **Bad Graduation** (certifying an unfit model) is our highest commercial risk and must be strictly prevented by evaluation gates.

#### 2. BYOI (Bring Your Own Infrastructure) Boundary
* Customers plug in their own compute (RunPod, Lambda, Modal), teacher models (OpenAI, Anthropic, DeepInfra), tool APIs, and datasets.
* **Security Law:** Customer-supplied infrastructure and tools MUST execute through controlled adapter boundaries (`ComputeAdapter`, `TeacherAdapter`, `ToolAdapter`). Customer code/MCPS MUST NEVER execute inside our core control plane.

#### 3. Single Codebase Principle
* The Lab is NOT a separate codebase from the core engine. It is the exact same portable engine running across both self-hosted enterprise environments and our hosted managed platform. Multi-tenancy MUST sit on top of `permanent_artifact_id`.

### FEATURE SPECIFICATIONS

#### Module 1: The AI VIN & Cryptographic "Birth Certificate" Standard
Every graduating model must be issued an immutable, signed **Birth Certificate** and **AI VIN** upon passing evaluation.

1. **AI VIN Format:**  
   `ITM-[FAMILY]-[DOMAIN]-[YYYYMMDD]-[HASH]`  
   *(Example: `ITM-LLM3-SEC-20261006-F8A2`)*
2. **Birth Certificate Manifest (JSON):**
   * **Place of Birth / Issuer:** `iTMounts AI Lab` (`itmounts.com`)
   * **`permanent_artifact_id`:** Immutable string (e.g., `art_01j982x7zk30q1`).
   * **Parentage:** Teacher model endpoints, versions, and dataset SHA-256 hashes.
   * **Medical/Safety Record:** Scores from Evaluation and Residency testing.
   * **Signature:** Cryptographic signature generated by the iTMounts Referee engine.

#### Module 2: The Double-Entry Credit Ledger & Failure Mechanics
Implement an **append-only immutable ledger** tracking `available`, `reserved`, `consumed`, and `refunded` credits.

* **Execution Flow:**
  1. **Start Experiment:** Reserve budget upfront (`balance_available` -> `balance_reserved`).
  2. **Categorize Run Outcome:**
     * `COMPETENCY_FAILURE` (Model failed exam): Legitimate experiment cost. Finalize charge (`CONSUMPTION`).
     * `CUSTOMER_INFRA_FAILURE` (Customer GPU/API timed out): Save experiment state. Release unused reservation (`RELEASE`).
     * `PLATFORM_FAILURE` (iTMounts orchestrator/evaluator bug): Trigger auto-retry. If unresolvable, execute `process_automated_platform_refund()` to restore reserved credits to `balance_available`.

#### Module 3: End-to-End Tracing & Telemetry
Every run MUST record an immutable knowledge trace:

`Credit Allocation -> Experiment -> Candidate -> Curriculum Version -> Teacher Model/Version -> Recipe/Version -> Compute Hardware -> Artifact Hash -> Evaluator Version -> Residency Logs -> Disposition -> Production Outcome -> Cost`

* **KPI Definitions to Enforce:**
  * **Selectivity:** `Competency Failures / Valid Evaluations` *(Excludes infrastructure failures)*.
  * **Infrastructure Failure Rate:** `System Failures / Total Attempted Runs`.
  * **Bad Graduation Rate:** Flag artifacts certified by evaluator that fail post-graduation production monitoring.

#### Module 4: Data Privacy & Machine-Enforced Tiers
Privacy settings MUST adhere to the trace schema:
* `PRIVATE`: Zero telemetry or data leaves tenant boundary.
* `AGGREGATE_METRICS`: Anonymized statistical operational relationships allowed.
* `RESEARCH_OPT_IN`: Explicit permission granted to improve distillation methodology.

### DATABASE SCHEMA REFERENCE (POSTGRESQL)

Developers must implement the database schema utilizing atomic row locks (`FOR UPDATE`), double-entry credit states, and immutable trigger constraints for `credit_ledger_entries`.

```sql
-- Core Types
CREATE TYPE data_privacy_tier AS ENUM ('PRIVATE', 'AGGREGATE_METRICS', 'RESEARCH_OPT_IN');
CREATE TYPE experiment_failure_type AS ENUM ('NONE', 'COMPETENCY_FAILURE', 'CUSTOMER_INFRA_FAILURE', 'PLATFORM_FAILURE');
CREATE TYPE transaction_type AS ENUM ('DEPOSIT', 'RESERVATION', 'CONSUMPTION', 'RELEASE', 'REFUND_PLATFORM_ERROR', 'DISPUTE_ADJUSTMENT');

-- Credit Ledger
CREATE TABLE org_credit_accounts (
    organization_id UUID PRIMARY KEY REFERENCES organizations(id) ON DELETE CASCADE,
    balance_available NUMERIC(15, 4) NOT NULL DEFAULT 0.0000 CHECK (balance_available >= 0),
    balance_reserved NUMERIC(15, 4) NOT NULL DEFAULT 0.0000 CHECK (balance_reserved >= 0),
    currency VARCHAR(10) NOT NULL DEFAULT 'ITM_CREDIT',
    updated_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
);

-- Immutable Ledger Entries
CREATE TABLE credit_ledger_entries (
    id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
    organization_id UUID NOT NULL REFERENCES organizations(id),
    experiment_id UUID REFERENCES experiments(id),
    transaction_type transaction_type NOT NULL,
    amount NUMERIC(15, 4) NOT NULL,
    balance_available_after NUMERIC(15, 4) NOT NULL CHECK (balance_available_after >= 0),
    balance_reserved_after NUMERIC(15, 4) NOT NULL CHECK (balance_reserved_after >= 0),
    idempotency_key VARCHAR(255) UNIQUE,
    description TEXT NOT NULL,
    metadata JSONB DEFAULT '{}'::jsonb,
    created_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
);

-- Permanent Artifact & AI VIN Registry
CREATE TABLE artifacts (
    permanent_artifact_id VARCHAR(128) PRIMARY KEY,
    vin VARCHAR(64) NOT NULL UNIQUE,
    experiment_id UUID NOT NULL REFERENCES experiments(id),
    base_model_family VARCHAR(100) NOT NULL,
    teacher_model_provenance JSONB NOT NULL,
    dataset_manifest_hash VARCHAR(64) NOT NULL,
    evaluation_scorecard JSONB DEFAULT '{}'::jsonb,
    residency_pass_status BOOLEAN NOT NULL DEFAULT FALSE,
    graduated BOOLEAN NOT NULL DEFAULT FALSE,
    issuing_authority VARCHAR(100) NOT NULL DEFAULT 'iTMounts AI Lab',
    birth_certificate_signature TEXT NOT NULL,
    created_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
);
```

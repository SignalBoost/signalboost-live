# COS Study-Method Architecture

Date: 2026-09-07
Status: design extension for SKILLS.md / COS University

COS must not use one universal study method. It should choose among internal RAG/library material, live internet research, owner-fed material, teacher/professor agents, peer/student A2A collaboration, structured courses and lectures, deliberate practice, labs/sandboxes/simulations, real projects/Production outcomes, feedback/tutoring, and fine-tuning/model adaptation where evidence justifies it.

Learning roles should remain explicit: student, peer, teacher/professor, and independent examiner. The same underlying model may serve different roles at different times, but evidence accounting must prevent self-grading and training/holdout contamination.

Automatic method selection should depend on the diagnosed gap. Stable conceptual gaps may begin with RAG and authoritative study; stale/current-world gaps require live authoritative research; procedural weaknesses require practice and tools; reasoning weaknesses benefit from contrasting examples, critique and peer challenge; advanced research gaps require primary literature, specialist discussion, reproduction/simulation and independent critique; repeated valuable failures that survive retrieval/practice/tool improvements may justify evaluating fine-tuning or another model-adaptation method.

COS should learn which study methods work best by subject and competency by comparing retention, transfer, cost, latency and verified Production outcomes.

The autonomous cycle should become:

observe performance/world/curriculum state -> rank learning opportunities -> choose subject/competency -> choose study-method portfolio -> acquire authorized material/resources -> study -> practice -> teacher/peer challenge when useful -> independent exam -> transfer exam -> real application where appropriate -> update transcript -> recertification -> next target.

RAG access, browsing volume, teacher agreement, A2A consensus, document ingestion and fine-tuning are not mastery. Graduation remains evidence-based through independent unseen performance and transfer.

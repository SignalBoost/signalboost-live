# ONE BRAIN — COS vs Concierge — OWNER LAW

This rule outranks older wording in this file if they conflict.

- **COS / Assistant** is the platform agent and the owner's personal agent. It is the only brain.
- **Concierge** is the public face. It is a rendering window. It must not reason separately.
- There are not two AIs. There is one COS answer. Concierge shows that answer after reserved company facts are removed.
- Reserved company policy, owner identity, model/provider/stack, internal metrics, and unpublished roadmap may be disclosed only on the COS/owner channel.
- On Concierge those reserved facts must be withheld. Ordinary questions (lists, flights, diagnosis method, writing) use the same COS answer on both surfaces.
- A developer who adds a second public reasoner, a Concierge-only knowledge path, or a different refusal for the same user text is violating this file.
